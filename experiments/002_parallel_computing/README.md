# Experiment 002: Parallel Computing and Multithreading

## Research Question

How does dividing a computational workload among multiple threads affect execution time, scalability, and correctness?

## Objective

To investigate parallel computation using C++ and understand how multithreading influences computational performance.

## Topics to Explore

- Processes and threads
- Concurrency and parallelism
- Thread creation and management
- Shared memory and race conditions
- Synchronization using mutexes
- Atomic operations
- Parallel speedup and efficiency
- Amdahl's Law

## Hypothesis

Dividing a sufficiently large computational workload among multiple threads can reduce execution time. However, performance improvement may not be proportional to the number of threads because of thread-management overhead, synchronization costs, and hardware limitations.
